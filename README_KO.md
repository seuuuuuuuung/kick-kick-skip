# KICK KICK SKIP v08

기존 페이지 파일명과 제품 이미지·모션을 유지한 수정본입니다. 메인 페이지는 index.html(About Us)입니다.

## 이번 수정
- 헤더 순서 Shop / About Us / Graphics, 투명 SVG 아이콘과 노란 선택 표시.
- 제공된 구성에 맞춘 촬영 화면, 결과 화면, 모바일 사진 수신 화면.
- 새로 제작한 실제 금속 질감 세탁기 드럼 프레임. 5초 후 한 장 촬영.
- 결과 화면에 QR 영역과 30초 카운트다운. 30초 후 index.html 자동 복귀.
- 다운로드 이미지는 사진·프레임·테이프·하단 로고만 포함하는 1224×1632 JPG.
- 홈 광고는 30초 동안 입력/스크롤/포인터 움직임이 없으면 닫힘. 새로고침하면 복원.
- 상세 하트 버튼 크기, 옵션에 따른 아래 구간 밀림, 구매 영역 스크롤 고정 유지. 스케치북 아래 추가 실선 제거.
- 푸터 배열과 포토부스 홍보 SVG 적용.

## 실행
Python 3 설치 후 압축을 푼 폴더에서 실행합니다.

```sh
python3 -m pip install -r requirements.txt
python3 server.py
```

브라우저에서 http://localhost:8000 을 엽니다. 카메라는 localhost 또는 HTTPS에서 이용해주세요. 주소창 카메라 권한을 허용해야 합니다.

## PC 사진을 휴대폰으로 전달하는 QR
사진을 올릴 서버와 휴대폰에서도 열리는 외부 HTTPS 주소가 필요합니다. 포함된 server.py를 해당 서버에서 실행하고 실제 공개 주소를 지정합니다.

```sh
KKS_PUBLIC_URL=https://실제-서버-주소 python3 server.py
```

서버의 앞단에 HTTPS를 연결하고 사진 저장 폴더를 지속 가능한 디스크에 두세요. 사이트와 사진 API를 같은 주소에서 서비스하는 구성을 기준으로 만들었습니다. 사진은 24시간 보관됩니다.

GitHub Pages에 정적 파일만 올리면 Python 사진 서버가 실행되지 않아 PC 사진 전달 QR은 작동하지 않습니다. SPARKON의 작은 기록 데이터와 달리 촬영한 사진 전체는 QR 주소 안에 담을 수 없어 서버 저장 방식으로 연결했습니다. 로컬 주소만 있거나 업로드에 실패하면 잘못된 QR 대신 해당 기기에서 사진을 저장하는 버튼을 표시합니다.

아이폰에서는 사진 다운로드를 누르면 지원되는 브라우저에서 공유 메뉴를 열며, ‘이미지 저장’을 선택합니다. 다른 환경에서는 JPG 다운로드를 사용합니다. 공유하기는 기기의 파일 공유 기능을 사용하며, 지원하지 않으면 다운로드로 연결됩니다.

## 확인한 범위
- 테스트 영상 스트림으로 5초 촬영 → 프레임 합성 → JPG 생성 → 서버 업로드 → 수신 페이지 조회 확인.
- 결과 화면의 30초 홈 복귀 확인.
- 393px 휴대폰 화면과 데스크톱 배치 확인. 브라우저 다운로드 버튼으로 JPG 파일 다운로드 확인.
- 원본 이미지·영상 유지, JavaScript 구문 검사.
- 실제 웹캠 및 iPhone/Android 사진 앱 저장, 외부 HTTPS 서버를 통한 QR 스캔은 실기기 확인이 필요합니다. 외부 서버 배포는 완료한 상태가 아닙니다.

실제 결제·배송을 하지 않는 전시 체험용입니다. 장바구니·주문은 해당 브라우저에 저장됩니다.
