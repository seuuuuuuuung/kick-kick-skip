# KICK KICK SKIP v06

기존 최신 웹 파일을 기준으로 이미지·상품 구성을 복원한 수정본입니다.

- 원본 이미지 크기 규칙을 덮어쓰던 공통 스타일 제거.
- 프로덕트 목록의 기존 3제품 구성을 유지하고 좌우 여백 확대.
- 상품 상단 원본 사진·설명 배치 복원. 옵션과 구매 동작 연동 유지.
- 상세 오른쪽 구매 영역 sticky 동작을 막던 전체 overflow 설정 수정.
- 메인 영상은 화면 너비와 높이에 맞춰 축소. 소리 버튼 제거, 무음 재생.
- 헤더 아이콘의 흰 배경은 multiply 합성으로 노란 브러시를 가리지 않도록 처리. 원본 픽셀 파일은 변경하지 않음.
- 촬영을 막을 수 있던 프레임 선로딩 의존과 폰트 대기를 제거. 촬영 결과에 저장/공유 버튼 추가.
- SPARKON의 QR 생성기를 사용해 다운로드 페이지 QR을 브라우저에서 생성.

## 실행

Python 3 설치 후 이 폴더에서 실행:

```sh
python3 -m pip install -r requirements.txt
python3 server.py
```

http://localhost:8000 으로 접속합니다. 파일을 더블클릭해서 여는 방식 대신 localhost 또는 HTTPS를 사용해주세요.

## 사진 QR 공유

SPARKON v40은 작은 기록 데이터를 URL의 # 뒤에 담고 결과 화면을 다시 그립니다. 카메라 사진을 전달하지는 않습니다. 원본 사진은 같은 방식으로 QR 하나에 담을 수 없어, 이 웹은 사진을 서버에 저장하고 수신 페이지 주소를 QR로 제공합니다.

서버를 외부 HTTPS 주소로 연결한 뒤 아래처럼 실제 주소를 지정해야 합니다.

```sh
KKS_PUBLIC_URL=https://실제-서버-주소 python3 server.py
```

GitHub Pages는 Python 서버를 실행하지 않으므로 정적 파일 업로드만으로 QR 사진 공유까지 활성화되지 않습니다. 서버 미연결 상태에서도 이 기기의 촬영 결과 다운로드 버튼은 독립적으로 동작하도록 구성했습니다. 사진은 서버에서 24시간 보관됩니다. 서버 배포/실제 외부 주소 연결은 이 파일에 포함된 완료 사항이 아닙니다.

## 검증

브라우저에서 메인 영상 재생, 프로덕트 원본 구성, 상세 이미지 및 오른쪽 구매 영역의 스크롤 고정을 확인했습니다. QR 생성기와 사진 서버 업로드·조회 로직 테스트를 통과했습니다. 실제 카메라 촬영과 iPhone/Android QR 스캔·사진 저장, 다양한 실기기 화면은 미검증입니다.

실제 결제·배송은 하지 않는 전시 체험용입니다. 주문·장바구니는 해당 브라우저에 저장됩니다.

## v07 변경 사항
- v06 원본 이미지·영상 파일을 그대로 유지했습니다.
- Philosophy 모션은 화면 폭 94% 기준, Graphics 모션은 전체 폭 기준으로 확대했습니다. 높이에 맞춰 영상을 축소하던 제한을 제거했습니다.
- 구매 버튼 줄: 빨간색 토글 하트 / 장바구니 / 바로 구매. 찜 상태는 마이페이지와 연동됩니다.
- 옵션 영역 높이에 따라 원본 상단 구간과 아래 장식 선이 함께 내려갑니다. 상단 원본 캔버스에서 상세 콘텐츠가 중복 노출되지 않도록 처리했습니다.
- 카메라 영상 준비 대기 및 프레임 합성 방식을 수정했습니다. 프레임을 내장하여 로컬 파일 출처 때문에 캔버스 저장이 차단되는 경우를 줄였습니다.
- 사진 선택 / 휴대폰 기본 카메라 촬영 경로를 추가했습니다. 결과물은 다운로드 링크 또는 지원 기기의 공유 메뉴로 저장합니다.
- 공개 HTTPS 사이트에서는 휴대폰 촬영 페이지 QR이 표시됩니다. 이 QR은 PC에서 찍은 사진 전송이 아니라, 방문자의 휴대폰에서 새로 촬영하는 경로입니다. 카메라 실행 방식은 휴대폰 브라우저에 따라 다를 수 있습니다.
- PC 사진 전달 QR은 기존 server.py 공유 서버 연결이 필요합니다. GitHub Pages만 사용하면 이 업로드 API는 작동하지 않습니다. localhost 주소는 휴대폰 전달 QR로 표시하지 않습니다.

검증: JavaScript 구문 확인 완료. 구매 화면에서 하트 상태·옵션 확장 확인. 검증 브라우저 파일 선택 단계가 멈춰 실제 카메라 촬영 및 최종 다운로드, 휴대폰 기기 검증은 완료하지 못했습니다.
